# Live Clock


## Description

The Live Clock is a simple web application created using HTML, CSS, and JavaScript. It displays the current time and updates automatically every second without requiring the user to refresh the page.

## Features

- Displays the current time in real time.
- Updates every second.
- Simple and user-friendly interface.
- Built using only HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

JavaScript uses the `Date` object to get the current time. The `setInterval()` function updates the displayed time every second, ensuring the clock always shows the current time.
